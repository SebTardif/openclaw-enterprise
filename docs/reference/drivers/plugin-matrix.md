# PluginDriver feature matrix

This matrix describes the source and test coverage at the commit below. It uses
current policy fields: plugin `enabled`, `toolDefaults`, `tools`, and typed
`driverPolicy`. Approval is `native`, `prompt`, or `approve`; reviewer is a
separate, capability-gated setting.

**Supported** identifies implemented behavior in the stated scope. **Partial**
identifies an implemented subset with the remaining limits listed in the cell.
The Codex policy implementation remains draft: complete effective-policy checks,
compatible session/reviewer routing, and real Agent enforcement are not yet
proven. This matrix does not establish deployed support.

For authoring controls, read [Agent plugin policy](../agent-plugins.md#approval-policy),
[bundled Driver mappings](plugin-bundled.md#native-mappings-and-limits), and the
selected Driver's `GET /installation` capabilities. The
[local docs preview](../../local-preview.md) and generated GitHub table use the
[same source data](../../assets/plugin-driver-matrix.json). The
[testing guide](../../testing/plugins.md#current-proof-notes) records proof limits.
